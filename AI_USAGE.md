# Использование генеративного ИИ

## Подготовка комплекта EK1 — 2026-10-03

- **Участник, ответственный за включение:** код M1/M2/M3 не установлен по переданным материалам; команда должна указать фактического ответственного перед сдачей.
- **Задача:** дополнить исходный архив до комплекта первой контрольной точки курса.
- **Использование:** ChatGPT/Codex прочитал архив и требования курса, предложил уточнения модели доступа, угрозы, решения, исходники API, сценарии проверки и инструкции.
- **Что вошло:** уточнения PROJECT/DFD/REQUIREMENTS; THREATS/DESIGN; src/TaskFlow.Api; Compose/Dockerfile; scripts; workflow; документы подготовки к защите и сдаче.
- **Проверка человеком:** на момент подготовки архива не подтверждена. Это обязательное действие команды перед включением результата в сдаваемую версию; автоматическая проверка ассистентом её не заменяет.
- **Проверка средствами ассистента:** статические проверки файлов/ссылок/синтаксиса Python описаны в [docs/VERIFICATION.md](docs/VERIFICATION.md). .NET и Docker отсутствовали; сборка API и интеграционный smoke не запускались.
- **Связанные результаты:** [CONTRIBUTIONS.md](CONTRIBUTIONS.md), [DESIGN.md](DESIGN.md), [THREATS.md](THREATS.md), [исходники](src/TaskFlow.Api/Program.cs).

Исходный AI_USAGE.md содержал декларацию отсутствия существенного использования. Она заменена, поскольку для этой версии уже не соответствует действительности. Команда должна указать только реально выполненную человеческую проверку, например конкретное уточнение требования или результаты своего запуска с commit/run URL; план не записывается как успешная проверка.

## Подготовка демонстрации на ноутбуке — 2026-10-05

ИИ сверил EK1, подготовил scripts/demo.py и docs/WINDOWS_DEMO.md, добавил прогон демо в CI и актуализировал подтверждения запуска по реальным GitHub Actions. Демонстрация выполняет настоящие HTTP-запросы к API и не подставляет ответы. Проверка человеком и ответственный M-код по-прежнему должны быть заполнены участниками по факту. Результаты автоматической проверки — docs/VERIFICATION.md и run соответствующего commit.
