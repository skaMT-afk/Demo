## Обязательные действия, которые нельзя подменить генерацией

1. Прочитать предложенные изменения и выполнить запуск по README. Внести фактический результат и версию в docs/VERIFICATION.md. При падении исправить причину, не отмечать PASS заранее.
2. Заполнить CONTRIBUTIONS.md фактическими результатами M1/M2/M3 и AI_USAGE.md — ответственными и проверкой человеком. Сейчас персональный вклад не подтверждён.
3. Уточнить статус калибровки PROJECT.md только по реальному ответу преподавателя; если ответа нет, не писать «согласовано».
4. Внести файлы из архива в рабочую копию существующего репозитория, сохранив её .git/историю. Не заменять репозиторий новым git init. Проверить diff и отсутствие .env/секретов.
5. Создать реальный commit и передать преподавателю публичный URL и этот hash либо tag ek1 к объявленному сроку. ZIP сам по себе не заменяет фиксацию версии.

## Команды после копирования и проверки

Из корня вашей существующей рабочей копии:

```sh
git status
git diff --stat
git add .
git diff --cached --stat
git diff --cached
git commit -m "Prepare EK1 security concept and API foundation"
git push
git rev-parse HEAD
```

Сначала просмотрите staged diff: в него не должны войти чужие незавершённые изменения или секреты. Команды commit/push выполняются командой — при подготовке ZIP удалённый репозиторий не изменялся.

Hash из последней команды относится к сдаваемой версии. Можно передать hash без тега. Если нужен тег, сначала убедитесь, что ek1 ещё не существует и не был сдан:

```sh
git tag -a ek1 -m "EK1 submission"
git push origin ek1
```

Не используйте force и не перемещайте ранее сданный тег. Если после фиксации нужна замена версии, согласуйте её с преподавателем.

## Проверка доступности

Откройте публичный URL конкретного commit в приватном окне браузера. Проверьте входную README, ссылки и успешный run CI именно этого commit. Убедитесь, что преподавателю отправлена зафиксированная версия, а не только ссылка на main.

Готовность документов не подтверждает личный вклад или запуск. Эти пункты оставлены явно открытыми, чтобы архив не содержал вымышленных свидетельств.
